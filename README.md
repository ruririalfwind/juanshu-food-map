# 眷属美食地图 · GitHub Pages 版

把微博博主 **@夜用型眷属** 的美食店铺做成地图：每个店铺一个点位，配**博文原文**作推荐语；店名/地址来自博文+博主本人评论区回复，经高德/携程/大众点评系交叉验证。

**在线访问**：`https://ruririalfwind.github.io/juanshu-food-map/`

## 更新机制

- **GitHub Actions 每周日 10:30（北京时间）自动增量更新**：只抓博主新发的微博（已爬过的不重复请求），新美食自动上地图
- 仓库 Actions 页面可**手动触发**（Run workflow）
- 需要微博登录 cookie 时，在仓库 Settings → Secrets 添加 `WEIBO_COOKIE`

## 数据说明

- 全量基线：5503 条微博 → 1417 条美食候选 → 53 条确认店名 → 51 家店铺
- 南沙农庄专项（评论区挖掘）：东记私厨（×3）、珍珍山庄、疍家妹疍家菜馆、潮汕韦记
- 复购次数 = 博主发布该店相关微博条数
- 坐标：验证店铺用平台坐标；未验证标注"博主自述·待核"，绝不虚构
